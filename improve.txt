# ACADIA V1.0.0 — FILE DELIVERY SYSTEM

---

## OVERVIEW

ACADIA uses a **hybrid delivery system** where different types of files come from different sources. This ensures the app works offline, costs nothing to maintain, and can be updated without releasing new APKs.

---

## FILE DELIVERY ARCHITECTURE

```
┌─────────────────────────────────────────────────────────────────────┐
│                         FILE DELIVERY SOURCES                       │
│                                                                     │
│  ┌──────────────────┐  ┌──────────────────┐  ┌──────────────────┐ │
│  │     ASSETS       │  │     GITHUB       │  │     IMGBB        │ │
│  │   (In APK)       │  │   (Repository)   │  │   (API)          │ │
│  │                  │  │                  │  │                  │ │
│  │ • Splash images  │  │ • Content JSON   │  │ • Profile photos │ │
│  │ • Subject icons  │  │ • Metadata       │  │                  │ │
│  │ • Payment icons  │  │ • Short notes    │  │                  │ │
│  │ • Social icons   │  │ • Quiz/Exam JSON │  │                  │ │

│  │   screenshots    │  │ • Past papers    │  │                  │ │
```

## 2. GITHUB REPOSITORY (Content Storage)

### What's Stored Here:
All educational content in JSON format. These are small files that contain metadata, structure, and links to larger files.

### Repository Structure:
```
ACADIA-CONTENT/
│
├── version.json                     # Content version number
├── subjects_list.json               # All subjects by path
│
├── high_school/
│   ├── grade_9/
│   │   ├── subjects.json
│   │   ├── mathematics/
│   │   │   ├── metadata.json       # Unit structure
│   │   │   └── unit_1/
│   │   │       ├── video.json      # YouTube link
│   │   │       ├── quiz.json       # Quiz questions
│   │   │       ├── exam.json       # Exam questions
│   │   │       └── flashcards.json # Flashcard data
│   │   ├── physics/
│   │   └── ...
│   ├── grade_10/
│   ├── grade_11/
│   └── grade_12/
│
├── university/
│   ├── freshman/
│   └── semester_2/
│
├── entrance/
│   ├── past_papers/
│   └── practice_questions/
│
└── common/
    ├── content_types.json
    └── languages.json
```

### Sample Files:

**version.json:**
```json
{
    "version": "1.0.0",
    "lastUpdated": "2026-07-17",
    "totalContent": 342
}
```

**metadata.json (Subject Structure):**
```json
{
    "subject": "Physics",

            "unit": 1,

            "content": {
                "video": {
                    "url": "https://youtube.com/watch?v=xxxxx",
                    "duration": "00:15:30"

                "short_note": {
                    "url": "https://github.com/.../physics_unit1_notes.pdf",
                    "pages": 12
                },
                "quiz": {
                    "url": "https://github.com/.../physics_unit1_quiz.json",
                    "questions": 10
                },
                "exam": {
                    "url": "https://github.com/.../physics_unit1_exam.json",
                    "questions": 30
                },
                "flashcards": {
                    "url": "https://github.com/.../physics_unit1_flashcards.json",
                    "cards": 20
                }
            }
        }
    ]

```

**quiz.json (Interactive Content):**
```json
{
    "title": "Physics Quiz",
    "questions": [
        {
            "id": 1,
            "question": "What is physics?",
            "options": ["A) Study of living things", "B) Study of matter and energy", "C) Study of chemicals", "D) Study of rocks"],
            "correct": 1,
            "explanation": "Physics is the study of matter and energy."
        }
    ]
}
```

### How GitHub Repository Works:
```
Admin Pushes Content to GitHub
        ↓
App Checks version.json Daily
        ↓
New Version Available?
    ├── Yes → Download New Metadata
    └── No → Use Cached Content
        ↓
Update Local Isar Database
        ↓
New Content Appears in App
        ↓
No APK Update Required
```

## 4. YOUTUBE (Video Embedding)

### What's Stored Here:
Educational videos are hosted on YouTube and embedded in the app.

### How YouTube Works in ACADIA:
```
Admin Uploads Video to YouTube
        ↓
Gets YouTube URL (e.g., https://youtube.com/watch?v=xxxxx)
        ↓
Adds URL to metadata.json
        ↓
App Reads YouTube URL
        ↓
Shows Video in App (No YouTube Branding)
        ↓
User Watches Video
        ↓
Video is Streamed (Requires Internet)
```

### Important: No YouTube Branding
- Videos appear as native app videos
- No YouTube logo, comments, or recommended videos
- Clean, distraction-free experience

### Option: Download Videos from GitHub
- Some videos can be downloaded to GitHub Releases
- Users can download for offline viewing
- No internet needed after download

```
    ├── completedExams
    ├── masteredFlashcards
    └── studyStreak

DownloadedContent
    ├── contentPath (local file)
    ├── contentType
    ├── downloadProgress
    └── isDownloaded

QuizResult
    ├── score
    ├── answers
    └── timeTaken

ExamResult
    ├── score
    ├── answers
    ├── unansweredCount
    └── autoSubmitted

StudyStreak
    ├── currentStreak
    ├── longestStreak
    └── studyHistory
```

### How Isar Works:
```
User Downloads Content
        ↓
Content Saved to Private Storage
        ↓
Metadata Saved to Isar Database
        ↓
User Studies Offline
        ↓
Progress Saved to Isar
        ↓
Internet Available?
    ├── Yes → Sync to Firestore
    └── No → Queue for Later Sync
        ↓
Data Persists Offline
```
